# Task 1: React Todo App

A beginner-friendly **ReactJS Todo App** built as part of a frontend learning challenge. It demonstrates key React concepts, uses **TailwindCSS** for styling, and includes optional Firebase features.

---

## ✅ What I’ve Built

I have successfully completed the **Todo App** as per the challenge requirements. Here's what the app includes:

### 🔧 Core Features:
- Add a task (text input + add button)
- Delete a task
- Edit/update task inline
- Mark task as completed (strike-through style)
- Filter tasks: **All**, **Completed**, **Pending**
- Data persistence using **localStorage**
- Styled using **TailwindCSS**

## 📚 React JS (Frontend Basics)

**Topics Covered While Building This App:**

- JSX syntax and rendering elements
- Functional components vs Class components
- Props and defaultProps
- React Hooks: `useState`, `useEffect`, `useRef`
- Controlled vs uncontrolled components
- Conditional rendering & list rendering (`map`, keys)
- Component communication (props drilling, lifting state up)
- Forms and input handling
- Routing with React Router (v6)
- UI design using TailwindCSS

---

## 🛠 Tech Stack

- **Frontend**: React JS
- **Styling**: TailwindCSS
- **State**: React Hooks
- **Routing**: React Router v6
- **Storage**: localStorage
